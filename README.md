# 🌕 한가위 테마 랜딩 페이지 (Vue + TypeScript + Vite)

배포 링크 : https://wlsdudwjd.github.io/vue-static-page/

**보름달·구름·연등 애니메이션**과 함께 한가위의 분위기를 담은 랜딩 페이지입니다.   
Vue 3 + TypeScript + Vite 환경에서 제작되었으며, 화면을 **좌우 여백 없이 꽉 채워** 시각적인 몰입감을 제공합니다.

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 🌕 **보름달 + 밤하늘** | CSS 그라디언트 기반의 무빙 나이트 스카이 |
| 🌫️ **구름 드리프트 애니메이션** | 느리게 흘러가는 구름 효과 |
| 🏮 **연등 랜덤 생성** | 부드럽게 떠오르는 랜턴 애니메이션 |
| 💬 **랜덤 소원 문구** | 버튼 클릭 또는 자동 변경 |
| 🧧 **모션 최소화 지원** | `prefers-reduced-motion` 대응 |
| ✅ **반응형 디자인** | 모바일 ~ 데스크톱 풀 지원 |
| ✅ **좌우 여백 없는 full-viewport UI** | `width: 100vw` + `overflow-x hidden` |

---

## 🏗 기술 스택

| 기술 | 설명 |
|---|---|
| **Vue 3** | Composition API + `<script setup>` |
| **TypeScript** | 안전한 타입 기반 개발 |
| **Vite** | 빠른 번들링/개발 환경 |
| **CSS 애니메이션** | 트윈클/부유/드리프트 효과 구현 |
